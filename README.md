# AI Trade

وكلاء ذكاء اصطناعي (Futures / Spot) على بيانات Binance الحقيقية. الوضع الحالي: **DEMO فقط** (أسعار حقيقية، تنفيذ تجريبي داخلي بدفتر محاسبي). **LIVE مقفل.**

## التشغيل (Termux)
```bash
pkg install python python-pandas python-numpy   # أو pip install -r requirements.txt
pip install -r requirements.txt
pkg install python-pillow                        # اختياري: صور التشارت لـ Telegram
python -m api.main                               # الخادم على 127.0.0.1:8001
```
متغيرات اختيارية: `DEMO_INITIAL_BALANCE`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
منفذ الخادم ثابت على `8001` لتوحيد اتصال التطبيق وخدمة Android.

## ما الجديد
- **Autopilot** (`core/autopilot.py`): يفحص السوق كل دقيقتين ويفتح صفقات DEMO وفق حدود المخاطر. مطفأ افتراضياً؛ يُفعَّل من شاشة «الأداء والآلي».
- **ماسح السيولة**: يبدأ بأعلى 30 زوجاً من حيث حجم التداول في Futures وأعلى 30 في Spot، مع فحص كل القائمة في دورة المسح.
- **بيانات محلية بالبث**: تسخين الشموع عند التشغيل عبر REST ثم تحديث 1m و5m ودفتر الأسعار عبر Binance WebSocket. تُجمّع 15m و1h محلياً من 5m؛ ويُحدّث إطار Spot 4h مرة كل ساعة. يحتاج Spot إلى 2,400 شمعة 5m كي يتوفر 200 بار 1h المطلوبة لمؤشر EMA200 دون تغيير الاستراتيجية.
- **دخول فوري**: لا يعاد تشغيل التحليل قبل التنفيذ؛ يُستخدم bid/ask المتدفق مع صلاحية 90 ثانية وانجراف أقصى 0.3 ATR في Standard.
- **لوحة Funnel**: أعداد المراحل الست وأسباب الرفض الخمسة الأولى في `GET /funnel` ولوحة التطبيق. تُعد الدورة ناجحة عند اكتمال 95% من رموزها دون خطأ قاتل.
- **حجم الصفقة**: سقف الهامش 25% من الرصيد لكل صفقة؛ عند تجاوز الحجم المحسوب للسقف يُخفّض الحجم ويُسجّل الخطر الفعلي.
- **سجل الصفقات** (`core/journal.py`) + **الأداء** (`/performance`).
- **التعلّم المنضبط** (`core/learning.py`): يوقف الأنماط ذات الأداء السلبي في Standard. Explore يتجاوز إيقاف النمط لجمع عينة منفصلة، ويضع `profile=explore` على كل صفقة.
- **سياق داعم** (`core/market_context.py`): funding, long/short, تدفق الحيتان, أخبار RSS. يؤكد أو يعترض فقط، والقرار فني.
- **تعويض الانقطاع**: عند عودة الشبكة تُعاد قراءة شموع الدقيقة لمعرفة هل لُمس الوقف أو الهدف أثناء الغياب.
- **Telegram**: رسالة + صورة تشارت (دخول/وقف/أهداف) عند فتح الصفقة وعند إغلاقها.
- **تشارت احترافي** في التطبيق (Lightweight Charts): EMA, Bollinger, VWAP, RSI, MACD, حجم، وخطوط الصفقات.

## Spot (DEMO)
- شراء فقط (Long) بسعر الـ ask وبيع بسعر الـ bid، مع وقف/هدف من خطة الصفقة وتعويض الانقطاع بالشموع.
- يمر عبر إدارة المخاطر والسجل والتعلّم والإشعارات.

## Profiles وواجهات المراقبة
- **Standard** هو الوضع الافتراضي: قواعد V3 كما هي، 90 ثانية و0.3 ATR.
- **Explore** اختياري من شاشة الأداء والآلي: مخاطرة 0.10–0.25%، صلاحية 120 ثانية وانجراف 0.5 ATR، ويتجاوز فيتو السياق البنيوي 4h/1h وإيقاف النمط بالتعلّم لغرض جمع البيانات فقط. لا يتجاوز خطة V3 أو SL/TP أو حد صافي RR ‏1.5. لا تستخدم صفقاته لتقييم الربحية.
- غيّر عاملاً واحداً فقط في كل أسبوع عند المقارنة.
- لا تحكم على الربحية قبل 150 صفقة على الأقل، مع مقارنة بخط أساس عشوائي.
- واجهات المراقبة: `GET /funnel`, `GET /market-data`, `GET /performance /journal /learning /autopilot` · `POST /autopilot /autopilot/run /learning/enable /scan/spot` · `POST /demo/open` يقبل `"domain": "futures|spot"`

## الاختبار التاريخي للاستراتيجية

من GitHub افتح **Actions → AI-Trader Historical Backtest → Run workflow**، واختر سنة أو سنتين أو ثلاث سنوات. سيختبر BTCUSDT وETHUSDT وBNBUSDT في Spot وFutures باستخدام الوكلاء وTrade Planner الفعليين، ويدرج التقرير والصفقات في Artifact قابل للتنزيل باسم `AI-Trader-Backtest`.

التكاليف المفترضة لكل جهة: Spot taker ‏0.10%، Futures taker ‏0.05%، وانزلاق 0.05% لكل جهة في السوقين. الاختبار لا يتضمن حالياً تاريخ Order Book أو مدفوعات Futures Funding، ويستخدم دخولاً عند افتتاح شمعة 5m التالية بعد تأكيد الإشارة على شمعة مغلقة. لذلك تُقرأ نتائجه كتقييم تاريخي محافظ، لا ضماناً للأداء المستقبلي.

التشغيل المحلي (بعد توفر بيانات الإنترنت):
```bash
python scripts/backtest.py --years 1 --symbols BTCUSDT ETHUSDT BNBUSDT
```
